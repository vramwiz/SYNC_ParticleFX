# パーティクル演出（SYNC_ParticleFX）

雨・雪・水しぶきなどを描き、画像のアルファ輪郭へ衝突・付着・蓄積させるAviUtl2用フィルタープラグインです。Windows 64bit / AviUtl2 2.1.16以降を対象とします。

## インストール・更新

1. AviUtl2を終了します。
2. `SYNC_ParticleFX.zip` を展開し、中の `SYNC_ParticleFX` フォルダーをAviUtl2の `Plugin` フォルダーへコピーします。標準の配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_ParticleFX` です。
3. AviUtl2を起動し、画像オブジェクトに「SYNC」グループの「パーティクル演出」を追加します。

更新も同じ場所へ上書きします。ZIPにはAUF2本体・このREADME・ライセンス類を収録します。アンインストール時は、AviUtl2を終了して同梱の5ファイルを削除してください。

## 使い方

1. 一番上の「素材」「発生」「動き」の3リストを選びます。
2. その下の「設定」を押すと、下のパラメータへ組み合わせを一括設定します。リストの選択だけでは演出は変わりません。
3. 発生量・速度・角度・重力・風などを個別に調整します。再び「設定」を押すと、関連項目を選択した組み合わせの基準値へ戻します。

| 項目 | 選択肢 |
| --- | --- |
| 素材 | 水、雪、砂、花びら、落ち葉、紙吹雪、ひょう、光、インク、スライム |
| 発生 | 広範囲、一斉発射、連続噴出、爆発、連続噴射 |
| 動き | 通常、横風、強風、渦、無重力 |

「雪＋広範囲＋強風」は吹雪、「水＋一斉発射＋通常」は一度だけ水をかける演出、「水＋連続噴出＋通常」は噴水、「水＋連続噴射＋通常」は横から水をかけ続ける演出です。水は発生方法に応じて雨・水をかける・噴水のスタイルへ切り替わります。下の「スタイル」「発生方式」は設定後も直接調整できます。

雨・スライム以外の組み合わせは、Full HDで形を見分けやすい大きさへ調整しています。「設定」は不透明度・遠近感・サイズ差・速度差・縦横比・回転速度・色差・ぼかし・残像も戻します。保存済みの設定を更新する場合は、3リストを選び直して「設定」を押してください。

連続噴射は画像の左端の外から右へ放ち、重力で曲がりながら対象の輪郭に当たって飛散します。人物へ水を当てる場合は、背景を抜いた人物素材の水が来る側に透明な余白を持たせ、「接触判定」を有効にしてください。「飛散量」「飛散速度」でしぶきを調整できます。ノズルを指定する場合は「自動配置」を無効にし、「位置X/Y」で発生点を透明な場所へ置き、「角度」「広がり」で向きと幅を調整します。水の角度0は右、180は左です。「継続時間」「反復周期」で間欠的な噴射にもできます。

位置・開始時刻・開始状態・時間補正・シード・色・接触・蓄積・描画範囲は維持します。自動配置・発生範囲・予備動作・継続時間・反復周期は組み合わせに合わせて再設定します。旧版の単一プリセットは3リストへ置き換えました。旧プロジェクトに保存済みのパラメータは「設定」を押すまで保持します。

広範囲は通常は画面上側から流入し、横風・強風では初期方向も斜めにして側面からも流入します。一斉発射は指定位置から右向き、連続噴出は上向き、爆発は全方向が基準です。発生点が元画像の不透明部分と重なる場合は「位置X/Y」を調整してください。

角度0は、雨・雪などが下、水をかける・インクが右、噴水が上です。重力角0は下、風向0は右です。重力0で無重力になります。連続型の「自動配置」を有効にすると進行方向の反対側から流入します。位置X/Yは画像中央を原点とします。

無重力は「動き」で選ぶほか「重力」0でも設定できます。全方向には「広がり」を360にし、「発生方式」を「爆発・放射」（単発）か「噴出」（連続）にします。指定位置から放つときは「自動配置」を無効にします。単発は「開始」の時刻に発生し、寿命後に消えます。繰り返す場合は「反復周期」を指定します。

「接触判定」を有効にすると、入力画像のアルファを判定します。蓄積量は0～100で、0なら蓄積を描きません。「表示方式」の「接触・蓄積」で、全画面の粒子と人物などへの付着を重ねられます。

描画範囲は入力画像と「下余白」を合わせたサイズです。範囲外はクリップされます。接触対象はこのフィルターに渡される画像だけです。雨・水・光には厚い蓄積を作りません。

## 開始状態

「時間補正」の下の「開始状態」を0～100で指定します。0は粒子・付着・蓄積のない降り始め、50は途中、100は従来の準備済みの状態です。初期値は100で、「設定」を押しても維持します。

連続型の粒子は予備動作の時間を割合で調整し、雪の蓄積も0から設定量へ育ちます。「予備動作」は0で自動、-1でなし、正数で基準秒数を指定する詳細設定として維持しています。「時間補正」は従来どおり表示時刻を秒数でずらします。発射・爆発・噴出の発生時刻も維持します。

## スライム

「素材」の「スライム」と発生・動きを選び、「設定」を押します。「接触」の「粘度」「まとまり」「付着力」「滴下時間」で調整できます。蓄積量・厚さは溜まり方に影響しますが、溜まった粒子も移動します。

輪郭や斜面に沿って流れ、くぼみでは一時的に溜まった後、画像の前面を通って下へ垂れます。画像を2Dの接触面として扱う演出用モデルです。重力0では自動の下向き滴下を行いません。スライムの見た目には左上から光を当てたような明暗が付きます。

画像の下端より先まで表示する場合は「出力」の「下余白」を増やします。元画像の配置と床位置を維持して下へ拡張します。下余白は「設定」では変更しません。

スライムは最大2,048粒です。粒子全体の履歴を計算するため、長い時間への初回シークには計算時間が掛かります。途中フレームや逆シークは同じ設定・入力で再現できます。

## 配布ZIPの作成・カタログ登録（開発用）

1. Delphi / Win64のReleaseをビルドします。既定の入力は `C:\ProgramData\aviutl2\Plugin\SYNC_ParticleFX\SYNC_ParticleFX.auf2` です。
2. [xxHash公式配布](https://github.com/Cyan4973/xxHash/releases/tag/v0.8.4)の `xxhsum.exe` を `Win64\Dependencies\xxHash-0.8.4` またはPATHが通った場所に置きます。
3. `setup\SYNC_ParticleFX.catalog.json` の `version` 末尾に公開タグと日付を設定します。初期値は `v1.0.0` です。次の版は末尾に追加します。
4. `setup\make_release_zip.bat` を実行します。`setup\SYNC_ParticleFX.zip` を作成し、ZIPに収録したAUF2と同じバイト列のXXH3-128を末尾バージョンへ記録します。
5. 同じソースをGitHubのタグへ保存し、ReleaseにZIPを添付します。カタログ登録には `SYNC_ParticleFX.catalog.json` を使用します。ハッシュはZIP作成時に、実際に同梱するAUF2の値へ更新されます。

別の出力フォルダーやxxhsumを使用する場合:

```powershell
.\setup\make_release_zip.bat -ReleaseDirectory "D:\Release" -XxhsumPath "D:\Tools\xxhsum.exe"
```

バッチは既存AUF2の梱包とローカルJSONのハッシュ更新を行います。プラグインのビルドとGitHubへの公開は別途行ってください。公開先の初期設定は `vramwiz/SYNC_ParticleFX` です。

JSONのパッケージID・GitHub取得先・ZIP名・インストール先・末尾バージョンの日付とハッシュ形式・削除先を確認してからZIPを更新します。対象は `VRAMWIZ.SYNC_ParticleFX`、ZIP名は `SYNC_ParticleFX.zip` です。削除先は下記5ファイルと一致させます。過去のバージョンのハッシュは維持し、末尾のバージョンだけを更新します。

ZIPとJSONは `setup` 内へ作成・更新します。バッチは別の作業フォルダーからも実行できます。必要ファイルの不足やJSONの不整合がある場合はエラー終了し、既存の配布ZIPを保持します。`xxhsum.exe` は開発用で、配布ZIPには含めません。

ZIP内の構成:

```text
SYNC_ParticleFX/
  SYNC_ParticleFX.auf2
  README.md
  LICENSE
  THIRD_PARTY_NOTICES.md
  ThirdParty/
    LICENSE.AviUtl2-SDK.txt
```
